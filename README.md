# Interview Tracker

Full-stack job application tracking system built with:

- Django + Django REST Framework
- JWT Authentication
- React
- Tailwind CSS
- Recharts

## Features

- User Registration & Login (JWT)
- Protected Routes
- Create / Edit / Delete Applications
- Status Tracking
- Pie Chart Analytics Dashboard
- Modern Tailwind UI

## Tech Stack

Frontend:
- React
- Tailwind CSS
- Recharts

Backend:
- Django
- Django REST Framework
- Simple JWT
