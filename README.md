## Technologies Used
- Django + Django REST Framework
- JWT Authentication
- React
- Postman for API Testing  

## Description
Users track their Interviews and job applications using this simple Interview tracker. The user can log in and add what job position they applied to from what company and indicate the current status. The website also has a built-in pie chart that dynamically updates as the status changes and more applications are added. The tracker can also be used to indicate notes for the specific job application the url linking to the job site.
